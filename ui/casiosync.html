Pair a GW‑BX5600
1. In Settings → Watch pairing, select the watch profile and GW‑BX5600 MIP protocol.
2. Press Pair Watch.
3. On the watch, hold C for at least 3 seconds until the Bluetooth symbol and CONNECT WITH A PHONE flash.
4. CasioSync learns the watch only after the connection and time write succeed.
Trigger a manual sync
1. Select the paired watch profile and press Sync selected watch now.
2. On a GW‑BX5600 in Timekeeping Mode, press D once to request immediate time correction.
3. If a previous wait window is already open, pressing Sync again restarts it instead of returning a generic busy error.
Always wait mode
When enabled, CasioSync continuously listens for sync requests from the selected paired watch. It never learns an unknown watch in this mode. Automatic windows listen for their assigned watch profiles, using their selected protocols.

Watch families & protocols

GW-BX5600 time sync is carried over from the working project. Additional models are protocol candidates from public implementations; device validation is pending. See watch compatibility.

  • GW-BX5600 MIP: inherited time sync, optional font setting and battery estimate.
  • Standard digital / hybrid (experimental): community protocol candidates for Bluetooth digital and hybrid families. Select the matching profile and protocol before pairing.
  • Analogue time-only: experimental support for compatible analogue families. Watch hand positioning and specialised training settings are not configured. Optional settings appear only for model families backed by the implemented protocol.

About

CasioSync V0.1 R4

An ESP32 Bluetooth time-sync companion for Casio watches. Wi-Fi supplies NTP time and a local web interface; each watch profile has its own pairing, protocol and optional display-font setting.

V0.1 R4 · 13 October 2026 · Derived from Time Transmitter V4.16 R1.

CasioSync on GitHub

Credits

Built on whitto's Time Transmitter / RadioClock work. Bluetooth protocol work and examples draw on casio-watch, gshock-api and Casio watch community projects; exact upstream references and library credits are listed in the repository README.

The original Time Transmitter lineage includes nisejjy by tarohs and ClockWaveXmitter improvements by 5Breeze. Their authorship is retained in the project history and credits.

CasioSync is an independent community project and is not affiliated with Casio. A successful Bluetooth time-write acknowledgement is delivery evidence; the ESP32 cannot verify the watch's displayed time.
