# V0.1 R2 reliability review

R1 source and both compiled targets were published before the full suite. That suite stopped on an unmatched closing parenthesis in the new watch-options storage test. R2 corrects that fixture and corrects a browser assertion to check the actual unavailable-feature behavior: hidden master/save controls, rather than a disabled hidden input. No production behavior was changed by either correction.

The firmware diff contains only the R2 version/changelog and regenerated UI version labels. Packet handling, state ownership, configuration, storage, scheduling, deadlines, memory/flash policy and all dependency sources are unchanged from the independently reviewed R1. Both board images are rebuilt to match the R2 labels and source; manifests and matching ELF symbols are regenerated. The existing source review remains applicable to unchanged behavior. No new callback/task/store or write loop is introduced.

GitHub release-asset upload returned Bad Content-Length despite explicit length; R2 uses board-only immutable GitHub tag ZIPs for compiled packages instead. Packages also remain tracked in the repository. Previous source tags stay immutable. The corrected watch-options fixture was checked in isolation; the full suite will be run only after R2 publication, following the requested release order. Actual results will be recorded afterward. Physical board/new-watch-setting acceptance remains pending.

Both final R2 targets compiled successfully and passed the actual ELF panic-gate/SNTP-hook checks. Node32s uses 1,384,409 bytes of reported sketch storage and 74,864 bytes of static RAM; C3 uses 1,449,169 and 61,040 bytes respectively. The generated application images fit the supplied 3 MB partition. Their packages retain matching symbols and hash manifests. A fresh render check passed and the added README preferences/alarm screenshots were visually inspected; the unsaved screenshot draft is reset before regression actions. No application settings are changed by screenshot capture.
